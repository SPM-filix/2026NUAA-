## 必测项

- **越权**：普通用户 Token 调用管理员接口；回收员查询他人流水
- **边界值**：0 积分兑换、库存为 1 时并发兑换、重量为 0 或极大值
- **并发**：多人同时兑换同一商品，积分不得为负、库存不得超卖
- **状态**：重复核销同一兑换码、撤销已撤销的流水
