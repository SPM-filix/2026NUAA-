## 3. 跑测试要用的东西

全部命令和参数见 [tests/README.md](../tests/README.md)，要点：

```bash
# 单元测试（39 个）
cd backend && JAVA_HOME="C:\Program Files\Eclipse Adoptium\jdk-21.0.13.9-hotspot" mvn test

# 冒烟（35 项断言）

# 并发（库存 1 时 20 并发）
ADMIN_INIT_PASSWORD=<管理员密码> node tests/smoke/concurrency-test.mjs

# 高并发（会创建 51 个测试用户和 2 个测试商品）
SMOKE_BASE=http://8.136.245.40 ADMIN_INIT_PASSWORD=<管理员密码> \
  node tests/load/high-concurrency-test.mjs
```

- 脚本默认打 `http://127.0.0.1:8080`，用 `SMOKE_BASE` 指向线上；
- **管理员密码向邓裕达索取**，不要写进 Postman 环境文件、报告或聊天群；
- 线上是生产库，跑高并发会新增测试用户和商品（商品会被下架，不能删），演示前可用 `docker compose down -v` 重置。

## 4. 改代码时的约定

- 模块层包（`controller/`、`service/`、`entity/`、`mapper/`）与核心层（`auth/`、`user/`、`catalog/`、`delivery/`、`exchange/`）并存，**新增 Mapper 必须用 `Module*` 前缀**，否则 Bean 名冲突启动失败。
- `appeal` 表有两套模型：核心 `user/entity/Appeal`（用户提交）与模块层 `entity/Appeal`（管理员处理），**改表结构时两处都要同步**。
- 模块层用 `common/R`，核心用 `common/api/ApiResponse`，JSON 结构一致，不要互换。
- 接口有变更先改 [docs/api.md](api.md)，再改代码；契约已冻结 v0.1。
- 管理端接口返回实体时必须 `@JsonIgnore` 掉 `passwordHash`，实体 `id` 需 `@JsonProperty("productId")` 之类的契约字段名映射（已全部加好，新增实体照做）。
