# 更新发布（拉代码 + 构建 + 启动 + 健康检查）

服务器已配置每日 03:30 自动备份（crontab，root 用户），日志在 `deploy/backup.log`。

常见问题：

| 现象 | 处理 |
| --- | --- |
| 浏览器打不开 80 | 检查阿里云安全组是否放行 80/443 |
| web 502 | `docker compose logs backend`，确认 DB 已 Healthy |
| 管理端刷新 404 | 必须访问 `/admin/`（带结尾斜杠） |
| 管理员登录失败 | 密码问题；账号初始化只在空库时用 `ADMIN_INIT_PASSWORD` |
| 磁盘不足 | `docker builder prune -f`、`docker image prune -f` |

## 4. 数据库结构（画 E-R 图用）

13 张业务表：

| 表 | 作用 | 关键关系 / 字段 |
| --- | --- | --- |
| `user` | 用户账号 | `phone` 唯一、`user_code` 6 位唯一、`points_balance`、`token_version` |
| `recycler` | 回收员 | 所属 `site_id`、`employee_no`、审核状态 `status` |
| `admin_user` | 管理员 | `username` 唯一 |
| `site` | 回收站点 | 被 recycler 引用 |
| `recycle_category` | 垃圾类别 | 编码 `code` 唯一，被 points_rule / delivery_record 引用 |
| `points_rule` | 积分规则版本 | `category_id` 外键，按 `effective_from` 取当前规则 |
| `delivery_record` | 投递流水 | `user_id`、`recycler_id`、`site_id`、`category_id`、`rule_id`、`weight`、`points`、`status` |
| `points_log` | 积分明细 | `user_id`，通过 `biz_type + biz_id` 关联流水/订单 |
| `product` | 商品 | `points_price`、`stock`、`version`（乐观锁）、`status` |
| `exchange_order` | 兑换订单 | `user_id`、`product_id`、唯一 `(user_id, idempotency_key)`、`redeem_code`、核销人/站点 |
| `announcement` | 公告 | 管理员发布 |
| `appeal` | 申诉 | `user_id`、`target_type + target_id` 指向流水或订单 |
| `upload_file` | 上传文件 | 本地磁盘记录 |

画图要点：

- `user` 1—N `delivery_record`、`points_log`、`exchange_order`、`appeal`
- `recycler` 1—N `delivery_record`，1—N `exchange_order`（核销人）
- `site` 1—N `recycler`、`delivery_record`
- `recycle_category` 1—N `points_rule`、`delivery_record`
- `product` 1—N `exchange_order`
- 流水/订单 1—N `points_log`（多态关联）
- `appeal` 多态指向 `delivery_record` 或 `exchange_order`
