## 6. 并发用例（`tests/smoke/concurrency-test.mjs`）

场景：库存为 1 的商品，同一用户 20 个并发兑换请求（不同幂等键），兑换前余额 45、商品价格 40。

| 指标 | 预期 | 实际 |
| --- | --- | --- |
| 成功订单 | 1 | 1 |
| 库存不足 `3002` | 其余请求 | 14 |
| 积分不足 `3001` | — | 5 |
| 商品库存 | 1 → 0 | 1 → 0 |
| 用户余额 | 45 → 5 | 45 → 5 |
| 该商品订单数 | 1 | 1 |
| 5xx / 未预期错误码 | 0 | 0 |

结论：条件更新扣积分 + 乐观锁扣库存有效，未出现超卖或重复扣分。
