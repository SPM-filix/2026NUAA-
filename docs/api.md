## 通用约定

- 基础路径：`/api`
- 认证：除注册、登录外，请求头携带 `Authorization: Bearer <token>`
- 统一响应体：

  ```json
  {
    "code": 0,
    "message": "ok",
    "data": {}
  }
  ```

- `code = 0` 表示成功；非 0 为业务错误码，具体码值在接口表中登记
- HTTP 状态码：`401` 未登录或 token 失效；`403` 已登录但无权限
- 分页参数：`page`（从 1 开始）、`size`；分页响应的 `data` 为 `{ "total": 0, "list": [] }`
- 时间格式：ISO 8601 字符串，如 `2026-11-09T15:30:00`
- 积分、库存为整数；重量为两位小数，单位 kg

## 角色与数据范围

| 角色 | 可访问范围 |
| --- | --- |
| 用户 `USER` | 仅本人资料、二维码、投递记录、积分明细、兑换记录 |
| 回收员 `RECYCLER` | 投递登记、核销兑换、本人工作台与流水（按登录人过滤） |
| 管理员 `ADMIN` | 规则配置、商品、账号、审计、统计；不参与称重录入与核销 |
