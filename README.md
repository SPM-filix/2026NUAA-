## 前端1-赵哲禹-用户端开发（居民/学生）
### 用户
1.账号管理：注册、登录、修改个人资料（手机号、地址等）、修改密码。
2.投递与积分查询：查看自己专属的“身份二维码/条形码”（供回收员扫码）；查看自己的历史投递记录（如：某日投递纸皮2kg，获得20积分）；查看当前积分余额及积分明细（收入与支出）。
3.商城兑换：浏览积分商城商品；使用积分兑换商品（兑换成功后生成唯一的兑换核销码）；查看自己的兑换历史记录及核销码状态（待核销/已核销）。
4.信息互动：查看系统公告、环保知识科普。
- 不能直接修改自己的积分余额（积分只能由回收员录入或系统奖励）
- 不能查看其他用户的投递记录、个人信息和积分
- 不能直接修改商品库存或上下架商品

## 前端2-杨光磊-管理端开发（管理员/回收员）
### 系统管理员
1.规则与基础配置（最高权限）：定义垃圾的类别（如废纸、塑料、金属）；设置各类垃圾的积分换算公式；维护回收站点信息。
2.商品与商城管理：发布新商品、编辑商品信息、修改商品图片；调整商品库存数量；设置商品上架/下架状态。
3.人员与账号管理：审核回收员的注册申请；新增或禁用用户/回收员账号；重置账号密码。
4.业务审计与异常处理：查看所有回收员的流水记录（监督是否有人乱录数据）；处理用户的异常申诉；强制撤销违规发放的积分；管理兑换订单（处理缺货退款或退回积分）。
5.数据统计与看板：查看全局的数据大屏（总回收量、总发放积分、分类占比饼图等）
- 不参与一线业务：管理员一般不直接操作“垃圾称重录入”和“核销订单”（职责分离原则），防止管理员自己录数据、自己发积分、自己核销，造成作弊
- 不能直接修改用户的密码（只能重置，让用户自己重新设置，保护用户隐私）

### 回收员
1.身份识别与积分发放：通过扫描用户的二维码或输入手机号，识别用户身份；选择垃圾类别、输入重量，系统自动计算并发放积分。
2.兑换核销：接收用户出示的兑换核销码，在系统中核销确认，并将实物礼品交给用户（系统自动将该订单状态改为“已完成”）。
3.业务查询：查看自己的工作台数据（如：今天累计回收了多少kg垃圾，发放了多少积分）；查看当前的积分换算规则（起参考作用）。
4.异常处理（有限度）：如果发现刚才称重录入错误，可以在规定时间（如5分钟内）发起“撤销申请”，或者由管理员授权后撤销
- 不能修改积分规则
- 不能管理商品和库存
- 不能查看其他回收员的业务流水
- 不能管理用户账号

## 后端开发1-邓裕达-核心业务、鉴权与高并发
### 安全与鉴权：
1.实现 JWT 登录认证。
2.实现 RBAC 权限控制（拦截器/注解），确保回收员无法调用管理员接口。
### 核心业务接口：
1.投递登记接口：接收回收员输入的数据，自动计算积分，并更新用户的积分余额。
2.积分兑换接口（技术难点）：处理积分扣减和商品库存扣减。需要加入乐观锁或 Redis 锁，防止高并发下积分扣成负数或商品超卖。
